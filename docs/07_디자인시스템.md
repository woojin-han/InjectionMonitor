# 07. 디자인 시스템

목업 3종에 공통으로 적용하는 규칙입니다. 대안마다 바뀌는 것은 색 테마와 배치뿐이고, **의미 색**과 **가격 표기 규칙**은 똑같이 씁니다. 테마는 디자인 확정 후 하나로 정합니다.

> 어두운 테마(B)에서는 1절의 의미 색 대신 밝은 버전을 씁니다: 진짜 `#3DDC97`, 부풀림 `#FF922B`, 최저가 `#9775FA`, 하락 `#4DABF7`, 상승 `#FF6B6B`.

## 1. 의미 색 (모든 대안 공통)
| 의미 | 색 | 쓰는 곳 | 함께 쓰는 기호 |
|---|---|---|---|
| 진짜 할인 | 초록 `#0F9D58` | 신뢰도 배지 | ✓ |
| 보통 | 회색 `#6B7280` | 신뢰도 배지 | – |
| 부풀림 의심 | 주황 `#E8590C` | 신뢰도 배지, 경고 | ! |
| 데이터 부족 | 연회색 `#9CA3AF` | 배지 | ⋯ |
| 역대 최저가 | 보라 `#7048E8` | 배지, 그래프 최저점 | ★ |
| 가격 하락 | 파랑 `#1C7ED6` | 변동 표시 | ▼ |
| 가격 상승 | 빨강 `#E03131` | 변동 표시 | ▲ |

> 한국 쇼핑몰 관례상 할인율은 빨강으로 표시합니다. 하지만 "가격 하락"은 파랑 ▼로 씁니다(주식 앱 관례). 색만으로 구분하지 않도록 **항상 기호를 함께** 붙입니다 (NFR-07).

## 2. 대안별 테마
`theme-factory` 스킬의 "새 테마 만들기" 방식으로, 대안마다 콘셉트에서 색과 글꼴을 뽑았습니다.

| 토큰 | A. 가격 줄자 | B. 세일 스티커 | C. 가격 영수증 |
|---|---|---|---|
| 배경 | `#EEF1F5` 연한 청회색 | `#D8DCE1` 매장 콘크리트 벽 | `#4A6274` 계산대 트레이 |
| 표면 | `#FFFFFF` | `#FFFFFF` 가격택 | `#FBFBF8` 감열지 |
| 글자 | `#1D2433` 남색 잉크 | `#22262D` | `#2B2F36` |
| 보조 글자 | `#5A6475` | `#626A76` | `#6B7280` |
| 강조 | `#F4C430` 줄자 노랑 | `#FF6A1A` 할인 스티커 주황, `#FFE047` 최저가 스티커 | `#FF9EC4` 형광펜 분홍, `#B8F27C` 형광펜 연두 |
| 모서리 | 8~12px | 6~10px (택은 위쪽이 더 둥글다) | 2~6px, 영수증 아래쪽은 톱니 모양 |
| 제목 글꼴 | IBM Plex Sans KR 700 | 도현 (매직펜 느낌) | 검은고딕 |
| 본문 글꼴 | IBM Plex Sans KR | Gothic A1 | 나눔고딕, 영수증 줄은 나눔고딕코딩 |
| 숫자 글꼴 | Archivo Narrow (좁은 숫자) | 도현 | 검은고딕, 나눔고딕코딩 |

## 3. 글꼴 크기
| 이름 | 크기 / 굵기 | 용도 |
|---|---|---|
| display | 28px / 800 | 상세 현재가 |
| h1 | 22px / 700 | 화면 제목 |
| h2 | 18px / 700 | 섹션 제목 |
| body | 14px / 400 | 본문 |
| caption | 12px / 400 | 정가, 날짜, 보조 설명 |
| price | 16px / 700, `tabular-nums` | 카드 현재가 (숫자 폭을 같게) |

## 4. 가격 표기 규칙
- 천 단위 쉼표와 "원": `79,000원`
- 정가는 취소선과 보조 색: ~~199,000원~~
- 할인율은 정수 %: `60%`
- 실질 할인율은 "평소보다 13% ↓"처럼 **기준을 문장으로** 밝힌다.
- 역대 최저가에는 항상 날짜를 붙인다: `역대 최저 69,000원 · 11/26`
- 수집 기간을 숨기지 않는다: `11/14부터 수집 (13일)`

## 6. 간격과 반응형
- 간격 단위: 4px (4, 8, 12, 16, 24, 32)
- 화면 폭: 모바일 < 640px (카드 2열), 태블릿 < 1024px (3열), PC (4열, 최대 폭 1200px)
- 모바일 좌우 여백 16px
