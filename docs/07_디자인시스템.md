**레이아웃 규칙**
- 목록: 행거 봉 아래에 가격택 4열(PC) / 3열(태블릿) / 2열(모바일). 택은 -2.5°~2° 사이로 살짝 기울이고, 마우스를 올리면 바로 선다.
- 상세: 위에서부터 작은 가격택과 가격 3종, 줄자, 판정 근거 3칸, 날짜별 그래프와 가격 알림.
- 필터: PC는 ☰ 필터 버튼을 누르면 패널이 열리고, 버튼 옆에 적용된 필터를 표시한다. 모바일(640px 이하)은 둥근 필터 버튼 줄.

아래 1~2절은 대안을 비교할 때 쓴 기록입니다.

## 4. 가격 표기 규칙
- 천 단위 쉼표와 "원": `79,000원`
- 정가는 취소선과 보조 색: ~~199,000원~~
- 할인율은 정수 %: `60%`
- 실질 할인율은 "평소보다 13% ↓"처럼 **기준을 문장으로** 밝힌다.
- 역대 최저가에는 항상 날짜를 붙인다: `역대 최저 69,000원 · 11/26`
- 기록 기간과 가상 데이터라는 사실을 숨기지 않는다: `90일치 기록 (가상 데이터)`
