## ① 서비스 안의 AI 기능

### F1. 품번·상품명 정규화 (필수, 난이도 포인트)
- **문제:** 같은 신발도 플랫폼마다 이름이 다릅니다.
  `나이키 에어포스 1 '07 화이트 DD1391-100` / `[NIKE] AIR FORCE 1 07 WHITE` / `에어포스1 로우 올백`
- **해결:** 먼저 정규식으로 품번을 찾습니다. 못 찾으면 OpenAI로 브랜드, 모델명, 품번, 카테고리를 **JSON 형식(Structured Outputs)**으로 뽑습니다. 이 결과로 `models` 테이블에 묶어 **플랫폼 비교**를 가능하게 합니다.
- **비용 관리:** 새 상품만 처리하고, 20개씩 묶어 한 번에 요청하며, 결과는 DB에 저장해 다시 묻지 않습니다.

```python
# crawler/normalize.py (뼈대)
from openai import OpenAI
client = OpenAI()  # OPENAI_API_KEY 환경변수

SCHEMA = {
  "type": "object",
  "properties": {"items": {"type": "array", "items": {
    "type": "object",
    "properties": {
      "idx": {"type": "integer"},
      "brand": {"type": "string"},
      "model_name": {"type": "string"},
      "style_code": {"type": ["string", "null"]},
      "category": {"type": "string", "enum": ["shoes","top","bottom","outer","etc"]}
    },
    "required": ["idx","brand","model_name","style_code","category"],
    "additionalProperties": False}}},
  "required": ["items"], "additionalProperties": False
}

def normalize(batch: list[str]) -> list[dict]:
    res = client.responses.create(
        model="gpt-5-mini",   # 개발 시점에 가장 저렴한 최신 mini 모델로 확인 후 교체
        input=[
          {"role": "system", "content": "패션 상품명에서 브랜드, 모델명, 품번, 카테고리를 추출한다. 품번이 상품명에 없으면 null. 추측하지 않는다."},
          {"role": "user", "content": "\n".join(f"{i}. {n}" for i, n in enumerate(batch))},
        ],
        text={"format": {"type": "json_schema", "name": "products", "schema": SCHEMA, "strict": True}},
    )
    import json
    return json.loads(res.output_text)["items"]
```
> 모델 이름과 SDK 사용법은 개발 시점의 OpenAI 공식 문서로 다시 확인하세요.

### F2. "지금 사도 될까?" 한 줄 요약 (필수)
- **입력:** 계산된 숫자만 줍니다 (현재가, 기준가, 역대 최저가, 정가 판매일 비율, 등급). AI가 숫자를 지어내지 못하게 하려는 것입니다.
- **출력 예:** "정가로 팔린 기록이 없어 60% 할인은 사실상 평소 가격이에요. 역대 최저가보다 10,000원 비싸니 기다려 보세요."
- **갱신:** 등급이나 현재가가 바뀐 상품만 다시 만들고 `product_stats.ai_summary`에 저장합니다. 웹은 저장된 문장을 읽기만 하므로 웹에는 API 키가 필요 없습니다.

### F3. 카테고리 자동 분류 (F1에 포함)

### 정확도 검증 (완성도 포인트)
- 무작위 100개 상품을 직접 정답과 비교해 **품번 정확도, 카테고리 정확도**를 표로 남깁니다.
- 프롬프트를 바꾼 전후의 정확도를 비교해 "개선 과정"을 보여줍니다.
